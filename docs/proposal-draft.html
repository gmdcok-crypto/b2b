구매·협력사 포털 제안 시안

2026-11-03 시안. 구매사 1곳과 그 협력사를 기준으로, 프로세스마다 누가 무엇을 하는지 적었다. 구매사와 협력사는 다른 도메인을 쓰고, API는 하나다. 확정된 요구와 아직 확인이 필요한 제안을 구분한다.

이 문서는 확인용 시안이다 역할 수, 단가를 가져오는 기준일, 기간이 겹치는 단가, 통화와 부가세, 엑셀 양식, 발주서 견본은 아직 고객 확인 전이다. 아래 확인 항목을 닫기 전에는 구현 요건으로 잠그지 않는다.

정산마감, 세금계산서, 지급 조건은 다루지 않는다.

제안 한 줄

구매사가 자기 주소에서 협력사, 품목, 계약단가, 발주를 만들고 확정한다. 협력사는 별도 주소에서 확정된 자사 발주와 자사 단가를 보고, 단가 변경만 요청한다. 확정 발주는 고치지 않고 취소 후 다시 낸다. 납품부터 정산, 알림, 첨부는 다음 합의로 남긴다.
